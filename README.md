# TableGamesBot

Telegram-бот для расширяемых настольных игр. Уже реализованы «Шпион» и
«Шляпа»: бот ведёт состояние и голосования, а живое общение остаётся у игроков.

## Быстрый запуск

1. Создайте бота в [@BotFather](https://t.me/BotFather) и задайте ему username.
2. Скопируйте `.env.example` в `.env`, заполните `BOT_TOKEN` и `ADMIN_IDS`.
   Telegram ID можно узнать у любого проверенного ID-бота.
3. Выполните:

   ```sh
   docker compose up -d --build
   ```

Данные SQLite и журнал изменений каталога находятся в `./data` и не исчезают
при пересборке контейнера. Логи приложения: `docker compose logs -f bot`.

## Первый каталог

Откройте личный чат с ботом и отправьте `/admin` с Telegram-аккаунта, чей ID
указан в `ADMIN_IDS`. Создайте хотя бы одну тему и одну активную локацию в ней.
Затем обычный игрок может открыть `/start` и создать комнату.

## Правила работы

- Бот удаляет обработанные команды и формы ввода. Внутри лобби, админки или
  партии он редактирует одну и ту же панель; при переходе в другой контекст
  удаляет старую и создаёт новую внизу чата. Закрепления не используются.
- После возвращения в главное меню лобби и идущие партии доступны через кнопку
  «Активные комнаты».
- Для комнаты требуется от 3 до 40 участников.
- Хост выбирает точное или случайное число шпионов, знакомство шпионов и набор
  тем для своей комнаты.
- В «Шляпе» хост задаёт круг, число карточек и время каждого из трёх раундов;
  бот удаляет введённые карточки из чата и показывает их только в личной панели.
- Удаления и изменения тем/локаций пишутся в `data/audit/catalog.jsonl`;
  удалённую тему с её локациями можно восстановить через админку.
